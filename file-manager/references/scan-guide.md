# 扫描诊断指南

## 扫描前准备

派分殿（Explore agent）扫描时，给清以下指令：

1. 目标目录的绝对路径
2. 扫描深度（默认 3 层）
3. 需要特别关注的模式（如"找出所有重复项目""标记大于 50MB 的文件"）

## 扫描要点

### 一、结构快照

用 `ls -la` 或 `find -maxdepth 3 -type d` 列出目录树。输出要包含文件大小、修改时间。

重点关注：
- 根目录下直接放的文件（通常该归类）
- 隐藏目录（`.xxx`）是否过多
- 同名目录是否出现在多处

### 二、问题分类

按以下标准扫描并分类：

| 问题类型 | 检测方法 | 示例 |
|---------|---------|------|
| **散落文件** | 检查目录中是否有多种不相关格式混放 | .py .png .docx 在同一层 |
| **重复项目** | `diff -rq dir1 dir2` 或对比目录名/内容 | skill-patrol 在根目录和 workspace 各有一份 |
| **大文件错位** | `find -size +50M` | 87MB tar.gz 放根目录 |
| **空目录** | `find -type d -empty` | temp/ 空置 3 天 |
| **过期副本** | 对比同名目录的修改时间 | projects/novel 比 workspace/novel 旧 2 天 |
| **错误放置** | SSH 密钥、配置文件出现在非标准位置 | .pub 文件在根目录 |
| **磁盘大户** | `du -sh * | sort -rh | head -10` | 找出占用最多的 |

### 三、隐藏问题

这些问题 `find` 不容易发现：

- **路径引用断裂**：检查 cron、systemd service、脚本中的绝对路径是否指向已不存在的目录
- **git 仓库状态**：各项目 .git/config 的 remote 是否正常，是否有未提交更改
- **权限问题**：关键目录是否权限过松或过紧

### 四、输出格式

诊断报告必须包含：
1. 当前目录树（2-3 层）
2. 问题清单（表格，按风险排序）
3. 磁盘占用 TOP 5
4. 一句话建议方向
