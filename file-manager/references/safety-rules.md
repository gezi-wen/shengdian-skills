# 安全红线

整理目录时必须遵守。违反任一条都可能造成严重后果。

## 绝对不碰

以下目录和文件，无论什么情况都不能移动、删除、重命名：

```
~/.ssh/           ← SSH 密钥
~/.gnupg/         ← GPG 密钥
/etc/             ← 系统配置（可以读，不能改）
/var/log/         ← 系统日志
~/.bashrc         ← Shell 配置
~/.profile        ← 登录配置
~/.gitconfig      ← Git 全局配置
```

此外，扫描时发现以 `.` 开头的隐藏配置目录（如 `~/.claude/`、`~/.config/`、`~/.cc-connect/` 等），可以读取内容、可以修改内部的路径引用，但**不能移动或重命名目录本身**。

## 需要用户明确确认

以下操作必须在变更清单中单独标注，等用户明确说"可以"再执行：

- 删除任何文件（包括空文件、临时文件）
- `rm -rf` 任何目录
- 修改 `/etc/systemd/system/` 下的服务文件
- 修改 crontab
- 重启任何 systemd 服务
- 移动正在被 systemd 服务引用的目录
- 强制推送 git（`--force`）

## 移动前检查

每步操作前确认三件事：

1. **目标父目录存在**：先建好，再移动
2. **不覆盖已有文件**：如果目标已存在同名文件，停下来问用户
3. **不在使用中**：检查是否有 systemd service 或 cron 引用了源路径

## 回滚原则

每步独立，出问题可以单独撤销：
- 移动操作 → `mv 目标 源` 回滚
- 删除操作 → 执行前先 `cp -a` 备份到 `/tmp/`
- 路径修改 → 记录改前内容，可以原样改回

## 禁止的操作

- `rm -rf /` 或任何递归删除根目录的操作
- 在不确定内容的情况下 `rm -rf` 任何目录
- 跳过用户确认直接执行中高风险操作
- 用 `--no-verify` 或 `--force` 绕过关卡
